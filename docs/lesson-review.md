## 1. 무엇을 우선 봐야 하나

우선순위 순입니다. 시간이 모자라면 위에서부터.

1. **사실 오류** — 숫자·날짜·인명·이름의 유래. 가장 치명적입니다
2. **엉뚱한 곳을 짚는 것** — 동그라미나 선이 다른 별에 그려지는 경우
3. **화면과 글이 어긋나는 것** — "화면 가운데에 국자가 보입니다"인데 구석에 있는 경우
4. **퀴즈** — 정답이 실제로 정답인지, 오답 해설이 오답인 이유를 제대로 말하는지
5. **문체 규칙 위반** — 아래 4번 항목
6. **오탈자·비문**

## 2. 자동 검사가 이미 잡는 것 (다시 볼 필요 없음)

```bash
cd apps/web-frontend
node tools/make-lesson-index.mjs
```

이것이 통과하면 다음은 **이미 보장됩니다.**

- `id` 가 파일 이름과 같음
- `level`(intro·basic·deep), `track`(principle·target·measure) 이 정해진 값임
- 필수 항목(title·subtitle·minutes·tags·steps) 이 다 있음
- **레슨이 짚는 천체 이름 71개가 전부 검색 색인에 있고, 이름이 겹치지 않음**

마지막 항목이 중요합니다. 같은 바이어 부호를 여러 천체가 주장하는 사고가
실제로 있었습니다(`* eta UMa` 가 알카이드가 아니라 3.16등급짜리 다른 별로 잡혀
북두칠성 국자가 무너져 있었음). 지금은 검사가 막습니다.

**반대로 자동 검사가 못 잡는 것**이 검수 대상입니다.

- 이름은 맞지만 **엉뚱한 별을 짚은 경우** (예: 국자 순서를 잘못 이음)
- 좌표로 짚는 표시(`{ra, de}`)의 값이 틀린 경우 — 유성우 복사점이 여기 해당
- 시야(`az`/`alt`/`fov`)가 주인공을 화면에 못 담는 경우
- 글의 사실 오류 전부

## 4. 문체 규칙 — 위반을 찾아 주세요

이 프로젝트는 **한국어·영어·일본어·스페인어**로 서비스합니다. 그래서 지키는
규칙이 있습니다.

1. **읽는 사람이 한국인이라고 가정하지 않는다.**
   - ✕ "우리나라에서는 안 보입니다" / "우리 조상들은"
   - ○ "북위 37도에서는 지평선 위로 올라오지 않습니다" / "한국에서는" / "동아시아에서는"
   - 한국 이야기를 **빼는 것이 아니라 밝혀 적습니다.**
2. **위도에 매인 사실은 나라 대신 위도로** 말합니다.
3. **모든 레슨은 밖에서 할 일로 끝납니다.** 마지막 단계가 화면 안에서
   끝나면 규칙 위반입니다.
4. **퀴즈 해설은 정답만이 아니라 오답이 왜 틀렸는지**를 말합니다.
5. **화면이 못 하는 것은 못 한다고 적습니다.** 일식 코로나, 유성, 변광성
   밝기 변화가 그렇습니다. 얼버무린 곳이 있으면 지적해 주세요.
6. 본문에 **연도를 되도록 쓰지 않습니다**(별 위치는 해마다 같으므로).
   달·행성·식처럼 연도가 꼭 필요한 주제만 밝혀 적습니다.

### 특히 손이 많이 간 단계 (여기부터 보셔도 좋습니다)

- `big-dipper` 1단계 — 국자를 잇는 선. 한 번 무너진 적 있음
- `proper-motion` 2·3단계 — 서기 5만 년·10만 년. 국자가 실제로 벌어지는지
- `polaris-changes` 2~7단계 — 기원전 2700년 ~ 서기 14000년. 극에 있는 별이 바뀌는지
- `eclipses` 4~6단계 — 스페인으로 관측지를 옮김. **5단계는 화면이 새까만 것이 정상**
- `meteor-showers` 1·4단계 — 복사점 동그라미가 페르세우스자리/쌍둥이자리에 맞는지
- `star-colors` 5단계 — 알비레오. 시야 0.08도에서 두 별이 금빛·푸른빛으로 갈라지는지
- `latitude-sky` 3~7단계 — 적도·북극·남반구·제주로 옮김
- `twilight` 1~5단계 — 하늘색이 단계별로 어두워지는지

### 6.2 레슨을 나갈 때 하늘이 돌아오는가

레슨은 하늘을 크게 바꿉니다. 나가면 **들어오기 전 상태로** 돌아와야 합니다.

1. `latitude-sky` 를 열고 5단계(남반구)까지 간다
2. 목록으로 나온다
3. 확인 — 관측지가 **원래 계신 곳**인가, 시각이 **지금**인가, 시간 배속이
   1인가, 대기·지형이 다시 켜졌는가, 시야가 원래대로인가

`star-brightness` 5단계(제주)와 `twilight`(북위 37.5도 고정)도 같습니다.
두 레슨은 중간에 `"home": true` 로 **레슨 안에서** 돌아옵니다.

### 6.3 모바일 (375px 폭)

- 포털이 가로로 넘치지 않는가
- 레슨 패널과 하늘이 함께 보이는가
- **천체 정보 카드가 접힌 채로 뜨는가.** 이름·종류와 함께 밝기·거리가
  한 줄로 보여야 하고, 눌러야 펼쳐집니다. 펼쳐도 화면 62%를 넘지 않습니다
  (이번에 고친 부분이라 특히 봐 주세요)

## 7. 알려진 한계 — 버그가 아닙니다

이것들은 이미 알고 내린 결정입니다. **다시 보고하지 않으셔도 됩니다.**

| 현상 | 사정 |
|---|---|
| 개기일식 때 화면이 새까맣다 | 엔진에 코로나가 없음. 레슨이 그 사실을 본문에서 밝힘 |
| 유성우인데 유성이 안 떨어진다 | 엔진의 유성 생성이 복사점을 쓰지 않음. 복사점만 짚고 밖으로 보냄 |
| 알골 밝기가 안 변한다 | 엔진이 변광을 계산하지 않음. 비교별 관측법을 가르치는 쪽으로 설계 |
| 서기 15만 년에서 화면이 멈춘다 | 엔진 한계. 레슨은 10만 년을 넘지 않음 |
| 관측지를 옮겨도 왼쪽 아래 지명은 그대로 | 스토어의 저장된 관측지. `latitude-sky` 가 본문에서 밝힘 |
| 천체 정보의 위키백과 요약이 영어 | 앱 기능. 레슨 범위 밖 |

## 8. 보고 형식

발견은 **표 하나로** 모아 주세요. 그대로 고칠 수 있는 형태면 가장 좋습니다.

```markdown
| # | 레슨 | 단계 | 분류 | 발견 | 근거/제안 |
|---|---|---|---|---|---|
| 1 | star-distance | 6 | 사실 | 베셀의 측정값을 0.31초각으로 적었는데 0.314가 통용됨 | ... |
| 2 | pleiades | 2 | 오탈자 | "묘성(昴星)" 한자 오기 | ... |
| 3 | spring-arc | 4 | 기능 | 스피카가 화면 밖에 있음 | az 105 → 115 |
```

- **분류**: `사실` · `기능` · `오탈자` · `문체` · `퀴즈`
- **단계**: 화면 오른쪽 위 `4 / 9` 의 앞 숫자
- 판단이 갈리는 것은 **틀렸다고 단정하지 말고** 근거와 함께 적어 주세요.
  특히 역사·문화 항목은 출처에 따라 설이 갈립니다
- 고치는 것은 원래 세션이 합니다. **파일을 직접 수정하지 말아 주세요.**
  같은 곳을 두 세션이 만지면 충돌합니다
