# 검수 결과 — 레슨 19편과 포털

[lesson-review.md](lesson-review.md) 의뢰에 대한 회신입니다. 레슨 19편 161단계
퀴즈 38개와 포털을 봤습니다. **파일은 고치지 않았습니다.**

검수 방법은 셋입니다.

1. **정적 검토** — 레슨 JSON 19개 전문과 `director.js` · `observing-panel*.vue` ·
   `selected-object-info.vue` 를 읽었습니다
2. **독립 계산** — HYG 항성 목록(엔진이 쓰는 것과 같은 출처)과 OpenNGC 로 별·성운
   좌표를, Meeus 알고리즘으로 해·달을, JPL 근사 궤도요소로 행성을 따로 계산해
   레슨이 박아 넣은 값과 대조했습니다. **엔진을 믿지 않고 다시 잰 것**입니다
3. **화면 확인** — 개발 서버를 띄우고 레슨을 단계별로 넘기며 시각·시야·표시·
   글과 화면의 일치를 봤습니다. 엔진 안의 세차 계산과 선 색깔은 콘솔에서 직접
   읽었습니다

`node tools/make-lesson-index.mjs ko` 는 통과하고, `index.json` 은 이미 19편으로
구워져 있습니다(다시 구워도 바이트가 같습니다). 포털도 "19 레슨 · 161 학습 단계"로
맞습니다.

것이 열 개 남짓**입니다. 특히 고유운동·박명·역행·충·월식 시각처럼 틀리기 쉬운
것들이 전부 정확했고, 6.2 레슨 이탈 복원과 6.3 모바일 카드는 규정대로 정확히

군데뿐입니다.
